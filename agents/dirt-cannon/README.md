# DiRT Canon Studio Desk

Run by **Kabloom** (Viral Content Studio). This is the working desk for The DiRT Canon —
metrics-engine content, publishing plans, track record, and performance.

## Layout
| Folder / file | What lives here |
|---|---|
| `STATE.md` | Verified snapshot of accounts, paths, pipeline (from the engine room). |
| `track-record/` | The honest hit/miss ledger. `TRACK-RECORD.md` + source CSVs/JSON. |
| `performance/` | Weekly performance reports (one file per pass). |
| `decisions/` | Dated decisions and owner approval gates. |
| `calendar/` | Publishing calendar / cadence notes. |
| `evidence/` | Raw artifacts copied for audit. |

## Rules of the desk
1. **Source-first.** Every number traces to the metrics handoff, a verified box score, or real
   platform data. No invented stats, wins, or engagement figures.
2. **Drafts are free; publishing is approved.** Nothing is posted, scheduled, or paid for without
   Chris saying yes in chat.
3. **Passes and holds are never counted as wins.** Track record is earned before it is advertised.
4. **Measurement before optimization.** If reach/click-through can't be measured, fix that first.
5. **Stale gate = cancelled gate.** Any item needing an owner decision lives 24 hours. Unanswered after
   that, it is **cancelled by default**, not carried forward, and never re-asked. Resurrection is explicit
   and per-item, only if Chris names it. Full rule: `decisions/STALE-POLICY.md`.

## Cadence
- **Sunday evaluation pass:** reconcile picks vs results, gather engagement, write the weekly report,
  propose adjustments.
- **Grading:** Oracle receipts within 48h of finals.
